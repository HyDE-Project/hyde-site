## Назва

`hyde-shell` - обгортка для виконання скриптів HyDE та розпізнавання середовища

## Синтаксис

```
hyde-shell [command] [arguments...]
hyde-shell [--help | help | -h]
hyde-shell [-r | reload]
```

## Опис

`hyde-shell` - це універсальний скрипт-обгортка, який виконує скрипти HyDE без розширень файлів і вирішує проблеми, пов'язані зі змінною PATH, коли користувачі можуть випадково перезаписати `~/.local/lib/hyde` у своєму PATH.

Розташований у `~/.local/bin/`, `hyde-shell` автоматично знаходить і виконує скрипти з бібліотечного каталогу HyDE, обробляючи як Python-скрипти (.py), так і shell-скрипти (.sh) без необхідності вказувати розширення файлів.

## Параметри

**`--help, help, -h`**
: Показати довідкове повідомлення з доступними командами та інформацією щодо використання.

**`-r, reload`**
: Перезавантажити середовище HyDE та оновити всі конфігурації.

## Вбудовані команди

**`wallbash`**
: Виконати скрипт wallbash для динамічної теми оформлення та керування кольорами.

**`python-env`**
: Керувати ізольованим віртуальним середовищем Python у HyDE. Повну документацію див. у [python-env](/uk/man-pages/python-env/).

```bash
hyde-shell python-env create        # Створити віртуальне середовище
hyde-shell python-env sync          # Синхронізувати залежності з pyproject.toml
hyde-shell python-env install <pkg> # Встановити пакет у venv HyDE
hyde-shell python-env rebuild       # Знищити та перестворити venv
```

## Виконання скриптів

`hyde-shell` надає доступ до всіх скриптів HyDE без необхідності вказувати розширення файлів:

```bash
hyde-shell waybar              # Виконує waybar.py
hyde-shell theme.import        # Виконує theme.import.py
hyde-shell wallpaper           # Виконує wallpaper.sh
hyde-shell screenrecord        # Виконує screenrecord.sh
hyde-shell python-env          # Керує Python venv HyDE
```

Обгортка автоматично знаходить і розпізнає всі скрипти в бібліотечному каталозі HyDE.

## Приклади використання

Виконати будь-який скрипт HyDE без розширення файлу:
```bash
hyde-shell waybar --help           # Запустити waybar.py з прапорцем допомоги
hyde-shell theme.import            # Запустити theme.import.py
hyde-shell wallpaper               # Запустити wallpaper.sh
```

Використати вбудовані команди:
```bash
hyde-shell wallbash                # Виконати скрипти wallbash у ~/.config/hyde/wallbash/scripts/

hyde-shell reload                  # Перезавантажити середовище HyDE
```

Передати аргументи базовим скриптам:
```bash
hyde-shell waybar --set layout-1   # Передати аргументи в waybar.py
```

## Основні можливості

- **Розпізнавання шляхів до скриптів**: знаходить скрипти в `~/.local/lib/hyde/` незалежно від конфігурації PATH
- **Обробка розширень**: автоматично додає відповідні розширення файлів (.py, .sh)
- **Незалежність від PATH**: працює незалежно від поточної конфігурації PATH або робочого каталогу
- **Керування середовищем Python**: надає `python-env` для створення, синхронізації та керування ізольованим venv HyDE

## Файли

**`~/.local/bin/hyde-shell`**
: Основний виконуваний скрипт-обгортка

**`~/.local/lib/hyde/`**
: Каталог, що містить усі скрипти та модулі HyDE

## Примітки

- Завжди надавайте перевагу `hyde-shell` над прямим виконанням скриптів для максимальної сумісності
- Розширення файлів необов'язкові та розпізнаються автоматично
- Майбутні версії HyDE дедалі більше покладатимуться на `hyde-shell` для виконання скриптів
