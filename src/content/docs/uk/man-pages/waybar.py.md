## Назва

`waybar.py` - скрипт керування конфігурацією Waybar у HyDE

## Синтаксис

```
waybar.py [-h] [--set SET] [-n] [-p] [-u] [-g] [-i] [-b] [-G] 
          [-c CONFIG] [-s STYLE] [-w] [--json] [--select] [--kill] 
          [--hide [{0,1,toggle}]]
```

## Опис

`waybar.py` - це комплексний скрипт керування конфігурацією Waybar, що є частиною HyDE, вашого середовища розробки.

Скрипт керує конфігураціями Waybar, що зберігаються в `~/.config/waybar/layouts/`, та відповідними стилями в `~/.config/waybar/styles/`. Він автоматично обробляє генерацію файлів включень, розмір іконок, оновлення радіуса заокруглення й забезпечує безперешкодне перемикання між різними конфігураціями Waybar.

## Параметри

### Керування макетами

**`--set SET`**
: Встановити конкретний макет за назвою. Файл макета повинен існувати в `~/.config/waybar/layouts/` з розширенням `.jsonc`.

**`-n, --next`**
: Перейти до наступного доступного макета в алфавітному порядку. Циклічно перебирає всі макети в каталозі макетів.

**`-p, --prev`**
: Перейти до попереднього доступного макета в алфавітному порядку. Циклічно перебирає всі макети в каталозі макетів.

### Операції оновлення

**`-u, --update`**
: Виконати повне оновлення всіх компонентів Waybar, зокрема:
  - Конфігурацій розміру іконок у файлах JSON
  - Радіуса заокруглення в CSS-файлах  
  - Генерацію файлу includes.json
  - Синхронізацію конфігурації та стилю

**`-g, --update-global-css`**
: Оновити лише файл global.css. Цей файл містить динамічні конфігурації розміру та родини шрифту, які можуть бути перевизначені темами через `hypr.theme` >> `$BAR_FONT`.

**`-i, --update-icon-size`**
: Оновити конфігурації розміру іконок у файлах JSON. Це вирішує проблему розміру іконок, яку не можна обробити безпосередньо через CSS Waybar.

**`-b, --update-border-radius`**
: Оновити конфігурації радіуса заокруглення в CSS-файлах. Це створює динамічний радіус заокруглення для груп, який адаптується до налаштувань заокруглення кутів Hyprland.

**`-G, --generate-includes`**
: Згенерувати файл `includes.json`. Цей файл містить:
  - Усі модулі з `~/.config/waybar/modules/`
  - Динамічні конфігурації, які Waybar не надає нативно
  - Розв'язання розмірів іконок для належного стилізування

### Шляхи конфігурації

**`-c CONFIG, --config CONFIG`**
: Вказати шлях до вихідного файлу `config.jsonc`. Це дає змогу використовувати конфігурації поза стандартним каталогом макетів.

**`-s STYLE, --style STYLE`**
: Вказати шлях до вихідного файлу `style.css`. Це дає змогу використовувати стилі поза стандартним каталогом стилів.

### Керування процесами

**`-w, --watch`**
: Увімкнути режим спостереження. Постійно відстежувати Waybar та автоматично перезапускати його, якщо процес завершиться аварійно. Корисно для підтримки постійного екземпляра Waybar.

**`--kill, -k`**
: Завершити всі запущені екземпляри Waybar та будь-які пов'язані скрипти спостереження. Це забезпечує чистий спосіб завершення всіх процесів Waybar.

**`--hide [{0,1,toggle}]`**
: Керувати видимістю Waybar:
  - `--hide 0` або `--hide show`: показати Waybar
  - `--hide 1` або `--hide hide`: приховати Waybar  
  - `--hide` або `--hide toggle`: перемкнути поточний стан видимості

### Інформація та перелік

**`--json, -j`**
: Вивести перелік усіх доступних макетів у форматі JSON. Корисно для написання скриптів та інтеграції з іншими інструментами.

**`--select, -S`**
: Відкрити інтерактивне меню rofi для вибору та перемикання між доступними макетами. Це забезпечує візуальний інтерфейс для перегляду та вибору з-поміж усіх конфігурацій макетів у `~/.config/waybar/layouts/`.

**`-h, --help`**
: Показати довідкове повідомлення з усіма доступними параметрами та завершити роботу.

## Файли

**`~/.config/waybar/`**
: Основний каталог конфігурації Waybar для користувацьких налаштувань

**`~/.config/waybar/layouts/`**
: Каталог, що містить файли конфігурації макетів Waybar (у форматі `.jsonc`)

**`~/.config/waybar/styles/`**
: Каталог, що містить CSS-файли стилів, які відповідають макетам

**`~/.config/waybar/modules/`**
: Каталог, що містить конфігурації окремих модулів

**`~/.config/waybar/includes/`**
: Каталог, що містить згенеровані файли включень і динамічні конфігурації

**`~/.config/waybar/includes/includes.json`**
: Автоматично згенерований файл, що містить усі визначення модулів та динамічні конфігурації

**`~/.config/waybar/config.jsonc`**
: Поточна активна конфігурація Waybar (тимчасовий файл, копія вибраного макета)

**`~/.config/waybar/style.css`**
: Поточний активний стиль Waybar (генерується автоматично, імпортує кілька CSS-файлів)

**`~/.local/share/waybar/`**
: Конфігурації Waybar, надані HyDE (лише для читання, не редагувати)

## Приклади

### Базове керування макетами

Вибрати макет інтерактивно:
```bash
waybar.py --select       # Відкриває селектор макетів rofi
```

Перейти до конкретного макета:
```bash
waybar.py --set khing
```

Циклічно перебирати макети:
```bash
waybar.py --next     # Наступний макет
waybar.py --prev     # Попередній макет
```

### Оновлення конфігурації

Оновити всі конфігурації:
```bash
waybar.py --update
```

Оновити окремі компоненти:
```bash
waybar.py --update-icon-size        # Оновити лише розміри іконок
waybar.py --update-border-radius    # Оновити лише радіус заокруглення
waybar.py --generate-includes       # Перегенерувати includes.json
```

### Керування процесами

Запустити Waybar у режимі спостереження:
```bash
waybar.py --watch
```

Керувати видимістю Waybar:
```bash
waybar.py --hide 1       # Приховати Waybar
waybar.py --hide 0       # Показати Waybar  
waybar.py --hide toggle  # Перемкнути видимість
```

Завершити всі процеси `waybar.py`, що фактично зупиняє режим `--watch`:

```bash
waybar.py --kill
```

### Отримання інформації

Інтерактивний вибір макета:
```bash
waybar.py --select       # Відкриває меню rofi для вибору макета
```

Вивести перелік доступних макетів:
```bash
waybar.py --json         # Формат JSON для написання скриптів
```

### Власні шляхи конфігурації

Використати власні файли конфігурації:
```bash
waybar.py --config /path/to/custom-config.jsonc --style /path/to/custom-style.css
```

## Робочий процес налаштування

1. **Перегляд і вибір макетів**: використовуйте `waybar.py --select`, щоб відкрити інтерактивне меню rofi та переглянути доступні макети

2. **Створення або копіювання макета**: почніть з наявного макета з `~/.local/share/waybar/layouts/` або створіть новий у `~/.config/waybar/layouts/`

3. **Генерація включень**: виконайте `waybar.py --generate-includes`, щоб переконатися, що всі модулі доступні

4. **Встановлення макета**: використовуйте `waybar.py --set <layout-name>`, щоб активувати вашу конфігурацію, або скористайтеся інтерактивним селектором за допомогою `waybar.py --select`

5. **Оновлення конфігурацій**: виконайте `waybar.py --update` після внесення змін, щоб переконатися, що всі компоненти синхронізовані

## Інтеграція з HyDE

`waybar.py` тісно інтегрований з екосистемою HyDE:

- **Інтеграція тем**: автоматично адаптується до поточних налаштувань теми HyDE
- **Динамічне стилізування**: оновлює радіус заокруглення відповідно до заокруглення вікон Hyprland
- **Керування шрифтами**: синхронізує шрифти з конфігураціями теми HyDE  
- **Система модулів**: керує модулями Waybar та конфігураціями, специфічними для HyDE


## Примітки

- Завжди використовуйте `~/.config/waybar/` для власних конфігурацій, ніколи не редагуйте файли в `~/.local/share/waybar/`
- Файл `includes.json` генерується автоматично, і його не слід редагувати вручну
- Назви макетів відповідають назвам файлів без розширення `.jsonc`
- Файли стилів повинні відповідати назвам макетів для автоматичного зіставлення (наприклад, `khing.jsonc` використовує `khing.css`)
