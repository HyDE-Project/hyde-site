Ці інструменти можуть покращити ваш робочий процес і допомогти отримати максимум від досвіду використання Hyprland! Їх протестовано, і вони добре працюють з HyDE також

### Шпалери

- [Hyprpaper](https://github.com/hyprwm/hyprpaper) ![c++][cpp] (блискавично швидка утиліта шпалер для wayland з керуванням через IPC)
- [awww](https://codeberg.org/LGFae/awww) ![rust][rs] (демон шпалер з живим перемиканням, чудовими анімаціями та підтримкою GIF)
- [mpvpaper](https://github.com/GhostNaN/mpvpaper) ![c][c] (демон шпалер, що обгортає MPV, корисний для відео та складнішого використання)
- [swaybg](https://github.com/swaywm/swaybg) ![c][c] (дуже простий демон шпалер, який використовується типово у sway)
- [waypaper](https://github.com/anufrievroman/waypaper) ![python][py] (GUI для встановлення шпалер)
- [waypaper engine](https://github.com/0bCdian/Waypaper-Engine) ![typescript][ts] (GUI для встановлення шпалер з можливістю відтворення списків)
- [wpaperd](https://github.com/danyspin97/wpaperd) ![rust][rs] (мінімалістичний демон шпалер для Wayland)


### Демони бездіяльності (Idle)

- [hypridle](https://github.com/hyprwm/hypridle) ![c++][cpp] (демон бездіяльності Hyprland)
- [swayidle](https://github.com/swaywm/swayidle) ![c][c] (демон бездіяльності, який використовується типово у sway, також єдиний, який мені вдалося знайти для wlroots)

### Блокувальники екрана

- [swaylock](https://github.com/swaywm/swaylock) ![c][c] (типовий блокувальник sway, дуже гнучкий і популярний)
- [swaylock-effects](https://github.com/mortie/swaylock-effects) ![c][c] (форк swaylock, але з ефектами ^)
- [waylock](https://codeberg.org/ifreund/waylock) ![zig][z] (невеликий блокувальник екрана для композиторів Wayland)
- [hyprlock](https://github.com/hyprwm/hyprlock) ![c++][cpp] (утиліта блокування екрана Hyprland з апаратним прискоренням GPU)
- [syslock](https://github.com/System64fumo/syslock) ![c++][cpp] (простий блокувальник екрана для wayland, написаний на gtkmm 4)

### Менеджери буфера обміну

- [clipman](https://github.com/chmouel/clipman) ![go][go] (простий менеджер буфера обміну для Wayland)
- [cliphist](https://github.com/sentriz/cliphist) ![go][go] (надійний менеджер буфера обміну для Wayland)


### Прості інструменти

- [Grim](https://git.sr.ht/~emersion/grim) ![c][c] (базовий інструмент для знімків екрана)
- [grim-hyprland](https://github.com/eriedaberrie/grim-hyprland) ![c][c] (форк Grim для прямої заміни з підтримкою протоколу захоплення вікон Hyprland)
- [Wayshot](https://git.sr.ht/~shinyzenith/wayshot) ![rust][rs] (базовий інструмент для знімків екрана, створений для швидкості й написаний на rust)
- [slurp](https://github.com/emersion/slurp) ![c][c] (базовий інструмент вибору області)
- [Hyprpicker](https://github.com/hyprwm/hyprpicker)  ![c++][cpp] (сумісна з wlroots піпетка кольору для Wayland, яка не викликає нарікань)
- [Wayfreeze](https://github.com/Jappie3/wayfreeze) ![rust][rs] (інструмент для заморожування екрана композитора Wayland)

### Запис

- [wf-recorder](https://github.com/ammen99/wf-recorder) ![c++][cpp] (простий засіб запису екрана, подібний до grim, але записує відео)
- [wl-screenrec](https://github.com/russelltg/wl-screenrec) ![rust][rs] (простий і ефективний засіб запису екрана для GPU AMD та Intel)
