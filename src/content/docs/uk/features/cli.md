HyDE-cli — це CLI-інструмент для [HyDE](https://github.com/prasanthrangan/hyprdots).
Цей репозиторій містить скрипти, які, хоч і не є ідеальними, можуть забезпечити зручніший спосіб керування вашим встановленням HyDE.
Наприклад, у нас є функціональний TUI-інструмент відновлення, що працює за списком `restore_cfg.lst`, параметри енергозбереження, які можуть бути корисними для ноутбуків, і багато іншого!

</div>

> 🚨 Хоча HyDE-cli є стабільним, важливо зауважити, що ці скрипти дійсно змінюють і _можуть_ потенційно порушити конфігурацію вашої системи.
> Просимо використовувати цей інструмент обережно та повідомляти про будь-які знайдені помилки.

## Встановлення

Для встановлення виконайте таку команду:

```sh
curl -sL https://raw.githubusercontent.com/HyDE-Project/Hyde-cli/master/install.sh | bash
```

> 📢 Для користувачів, які не мають прав root:
> `export HYDE_LOCAL=1`, щоб встановити цей пакет локально

Інші робочі варіанти встановлення наведено нижче.

### Arch Linux

Використайте свій улюблений AUR-хелпер `paru` або `yay`:

```sh
paru -Sy hyde-cli-git
```

```sh
yay -Sy hyde-cli-git
```

Використання makepkg:

```sh
git clone https://aur.archlinux.org/hyde-cli-git.git
cd ./hyde-cli-git
makepkg -si
```

### Make

Встановіть необхідні залежності: `git make fzf tree ttf-jetbrains-mono-nerd`.

Клонування:

```sh
git clone https://github.com/HyDE-Project/Hyde-cli
cd ./Hyde-cli
```

Для встановлення:

```sh
make
```

Для видалення:

```sh
make uninstall
```

Для оновлення:

```sh
make update clean install
```

> 📢 Користувачам без прав root слід додати цей прапорець для `make`: `make LOCAL=1`

> ⚠️ Якщо ви раніше встановили HyDE без використання CLI, ви все одно можете використовувати CLI для керування своїм встановленням.
> Для цього поєднайте прапорці --dir та --link, вказавши шлях до розташування локально клонованого репозиторію.
>
> Наприклад:
>
> ```sh
> Hyde-install --dir /path/to/cloned/hyde --link
> ```

#### Інструкції зі встановлення HyDE за допомогою Hyde-install

> 📢 Для найкращого досвіду рекомендується виконати чисте встановлення HyDE.

1. **Базове встановлення**

- Щоб встановити HyDE з типовими налаштуваннями, просто виконайте таку команду:

  ```sh
  Hyde-install
  ```

> ⚠️ _Вже маєте HyDE, перш ніж дізналися про цей CLI?_
> Просто виконайте цю команду
> `Hyde-install --link --dir ~/HyDE`
> Зверніть увагу, що `~/HyDE` — це шлях до каталогу клону.
> Див. розділ **Розширене встановлення** нижче для отримання додаткової інформації.

2. **Розширене встановлення**

- Для більшого контролю над процесом встановлення можна використовувати такі параметри:

  - **Вказати локальний каталог**: щоб клонувати HyDE у певний локальний каталог і виконати встановлення, використайте прапорець `-d` або `--dir`, за яким слідує шлях до каталогу.

    ```sh
    Hyde-install --dir /path/to/directory
    ```

  - **Вказати віддалений Git-репозиторій**: щоб клонувати HyDE з певного віддаленого Git-репозиторію, використайте прапорець `-g` або `--git`, за яким слідує URL репозиторію.

    ```sh
    Hyde-install --git https://host/owner/repository
    ```

  - **Пов'язати локальний Git-репозиторій**: щоб пов'язати локальний Git-репозиторій, використайте прапорець `-l` або `--link`.

    ```sh
    Hyde-install --link
    ```

3. **Синхронізація змін**

- Якщо ви хочете отримати останні зміни з репозиторію `hyprdots/HyDE` і застосувати їх до свого локального встановлення

  ```sh
  Hyde update
  Hyde restore Config
  ```

> ⚠️ Якщо ви раніше встановили HyDE без використання CLI, ви все одно можете використовувати CLI для керування своїм встановленням.
> Для цього поєднайте прапорці --dir та --link, вказавши шлях до розташування локально клонованого репозиторію.
>
> Наприклад:
>
> ```sh
> Hyde-install --dir /path/to/cloned/hyde --link
> ```
