HyDE — це охайне, естетичне та модульне середовище розробки для Hyprland на
Arch. Основний фокус — на послідовному вигляді й відчутті, розумних параметрах за замовчуванням та оновленнях,
які не заважають вашій роботі.

## Що ви тут знайдете

- Покроковий процес встановлення та поради щодо першого запуску
- Продуману модульну структуру, яка тримає налаштування впорядкованими
- Інструменти для тем оформлення та галерею спільноти для обміну стилями
- Довідкову документацію щодо вбудованих утиліт і команд

## Швидке встановлення

```sh
pacman -S --needed git base-devel
git clone --depth 1 https://github.com/HyDE-Project/HyDE ~/HyDE
cd ~/HyDE/Scripts
./install.sh
```

Після завершення встановлення перезавантажте систему до менеджера дисплеїв і увійдіть у HyDE.
