## Використання

> - Переконайтеся, що ви встановили [HyDE](https://github.com/HyDE-project/hyde)

### Інтерактивний імпорт тем з галереї за допомогою hyde-shell

```shell
hyde-shell theme.import --select
```

### Імпорт конкретної теми за назвою і URL за допомогою hydectl 

```shell
hydectl theme import --name "Catppuccin Mocha" --url  "https://github.com/HyDE-Project/hyde-themes/tree/Catppuccin-Mocha"
```

### Оновлення конкретної теми

```shell
hyde-shell theme.import --fetch "Theme Name"
```

### Оновлення лише тем, розташованих у '$XDG_config/hyde/themes'

```shell
hyde-shell theme.import --fetch all
```


### Вибір активної теми за допомогою rofi

```shell
hyde-shell theme.select
```

### Встановлення теми напряму

```shell
hydectl theme set "Theme Name"
```

## Керування шпалерами

### Інтерактивний вибір шпалери за допомогою rofi

```shell
hyde-shell wallpaper -S
```

### Встановлення конкретної шпалери

```shell
hyde-shell wallpaper -S --select /path/to/wallpaper.jpg
```

### Список доступних шпалер

```shell
hyde-shell wallpaper list
```
