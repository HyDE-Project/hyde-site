## Що таке HyDE?

HyDE — це естетичне, модульне та сумісне з XDG середовище розробки для
Hyprland на Arch, орієнтоване на чіткий дизайн, зручність підтримки та приємний UX.
Воно відокремлює основні скрипти від користувацьких налаштувань, що робить оновлення безпечнішими та простішими.

## Встановлення

```sh
pacman -S --needed git base-devel
git clone --depth 1 https://github.com/HyDE-Project/HyDE ~/HyDE
cd ~/HyDE/Scripts
./install.sh
```

Потрібна допомога? Дивіться повний посібник: [Початок роботи > Встановлення](/uk/getting-started/installation)
